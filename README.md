# مساعد محتوى زِيّ (ZEY Content Assistant)

أداة ويب داخلية يستخدمها موظفو متجر **زِيّ** لإنتاج محتوى سوشال ميديا على هوية البراند، بدون خبرة تسويقية. معزولة تماماً عن حسابك ومحادثاتك — مكتفية ذاتياً.

## شو فيها

- **✍️ كابشن** — كابشن بالعربية + العبرية + هاشتاغات، حسب عمود المحتوى والموضوع.
- **💡 أفكار** — 5 أفكار منشورات أسبوعية موزّعة على الأعمدة الأربعة.
- **💬 رد عميل** — رد مقترح بالعربية والعبرية بنبرة زِيّ.
- **📚 المكتبة** — كل المخرجات محفوظة في **مخزن مشترك** بين كل الموظفين، مع اعتماد/إلغاء/حذف.
- **📊 تحليل** — إحصائيات + زر "حلّل وطوّر" يعطي اقتراحات عملية لتطوير المحتوى.
- **التعلّم:** المخرجات المعتمدة (⭐) تُستخدم تلقائياً كأمثلة (few-shot) لتحسين توليد الكابشنز اللاحقة.

## الأمان والعزل

- مفتاح API وسياق البراند وكل البرومبتات تعيش على **الخادم فقط** — لا شيء حسّاس في كود الواجهة.
- الواجهة تتكلم مع الخادم فقط؛ الخادم هو اللي يكلّم الذكاء الاصطناعي.
- لا اتصال بحسابك أو Cowork أو أي محادثة.

## التشغيل محلياً

```bash
cd zey-content-assistant
npm install
cp .env.example .env      # ثم ضع مفتاح ANTHROPIC_API_KEY بداخله
npm start
```

افتح: http://localhost:3000

## النشر (ليصير رابط للموظفين)

أي استضافة Node تنفع (Render, Railway, Fly.io, VPS...). الخطوات العامة:

1. ارفع المجلّد إلى المنصّة (أو اربطه بـ GitHub).
2. أمر التشغيل: `npm start` — Node 18 أو أحدث.
3. أضف متغيّر البيئة `ANTHROPIC_API_KEY` في إعدادات المنصّة (لا تضعه في الكود).
4. تأكّد أن مجلّد `data/` قابل للكتابة ودائم (persistent disk) حتى لا تضيع المكتبة عند إعادة التشغيل.
5. شارك الرابط الناتج مع الموظفين — يفتحونه مباشرة بدون أي حساب.

## المخزن المشترك

تُحفظ المكتبة في `data/library.json` على الخادم. كل عنصر:

```json
{ "id": "...", "type": "caption|idea|reply", "pillar": "...", "input": "...", "output": "...", "approved": false, "ts": 1234567890 }
```

> ملاحظة: ملف JSON يكفي لفريق متجر صغير. لو كبر الاستخدام كثيراً، يُنصح لاحقاً بنقل المكتبة إلى قاعدة بيانات (SQLite/Postgres) — التغيير محصور في دوال `readLib`/`writeLib` بملف `server.js`.

## التطوير المستقبلي

- تحديث "بريف زِيّ" يدوياً مع تراكم الملاحظات.
- ربط النسخة المستضافة بأنظمة زِيّ الحقيقية (كتالوج، أسئلة شائعة، Monday) لمعلومات حيّة.
